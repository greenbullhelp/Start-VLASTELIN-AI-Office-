# Джарвіс — персональний AI-асистент

Джарвіс працює цілодобово на сервері, приймає задачі з телефона текстом і голосом, роздає роботу команді агентів
і звітує. Мозок — [Hermes Agent](https://github.com/NousResearch/hermes-agent) від Nous Research на моделях Claude;
керування — приватна веб-панель «Командний центр» (лише для власника, пароль + 2FA).

Напрями: ігри (карткова гра з донатами й банерною рекламою), монтаж відео, аналітика й торгівля золотом (поки лише демо), дослідження.

## Статус проєкту

| Етап | Що входить | Стан |
|---|---|---|
| 1. База | Docker Compose (Hermes + панель + HTTPS), вхід з 2FA, чат текстом і голосом (хвиля), середня модель, правила, журнал, «Стоп» | ✅ готово, протестовано |
| 2. Команда | Контролер, 4 виконавці, блокування файлів, автоперемикання моделей, вартість задач, денний ліміт | ✅ готово, протестовано |
| 3. Огляд | Щоденний звіт, розділи Ринок / Гра та бізнес / Звіти, жива схема агентів, Telegram | ✅ готово, протестовано |
| 4. Вузол на ПК | Клієнт Windows + Tailscale, автозапуск, значок онлайн/офлайн; графіка (ComfyUI/SD), відео (FFmpeg + Whisper); білий список | ✅ готово, протестовано наскрізно |
| 5. Ігровий агент | Імпорт сценарію VLASTELIN, каталог карток, єдиний стиль графіки, прототип гри, монетизація | ✅ готово, протестовано |
| 6. Трейдинговий агент | Аналітика золота, сигнали, журнал, демо-рахунок, ліміти ризику, автостоп | ✅ готово, протестовано |

Останнє оновлення: 19.11.2026. Тести: `cd panel && python -m pytest -q` (31 тест) і `cd game-starter && node engine.test.mjs` — усі проходять.
Перевірено з реальним Hermes Agent 0.23.2 у Docker (запуск задачі, статус, «Стоп», обробка помилок) і з реальним клієнтом ПК-вузла
(FFmpeg, імітація ComfyUI).

**Чого не можна було перевірити без власника**: справжні відповіді моделей (потрібен ваш ключ Anthropic), доступ сервера до
Binance/OKX, Telegram-бот, ComfyUI на вашій відеокарті, вхід з iPhone. Список перевірок — нижче.

### Що перевірити власнику після встановлення
1. Вхід: пароль → 2FA через «Паролі» iPhone → панель відкривається; повторний вхід із кодом.
2. Чат: «Привіт» (дешева модель) і «Склади план відео про золото на тиждень» (середня) — відповіді й ціна під ними.
3. Голос: 🎤 → сказати задачу → хвиля, текст розпізнано, Джарвіс відповів.
4. Команда: «Важливо: проаналізуй баланс стартових карток» → кроки агентів, перевірка Контролера, звіт у чаті.
5. «СТОП» → усе зупинилось; «ПРОДОВЖИТИ».
6. Ринок: за хвилину з'являються ціна, графік і тренд (якщо ні — у картці буде причина).
7. Telegram: «Привіт», `/status`, `stop`, `/resume`.
8. ПК-вузол: значок зелений, у «Агентах» ПК онлайн; «Гра та бізнес» → «Намалювати» → картинка з'являється в каталозі.
9. Щоденний звіт о 21:00 у панелі й Telegram.

**Що потрібно від власника, щоб запустити**: VPS, ключ Anthropic API, виконати [інструкцію встановлення](docs/SERVER_SETUP.md).

## Структура

```
docker-compose.yml   три служби: hermes, panel, caddy
Caddyfile            HTTPS для панелі
.env.example         шаблон налаштувань (справжні ключі — лише в .env на сервері)
hermes/              конфігурація й характер Hermes (config.yaml, SOUL.md)
panel/               веб-панель: FastAPI (app/) + інтерфейс без збірки (static/) + тести (tests/)
node/                вузол для ПК з Windows (Python): FFmpeg, Whisper, ComfyUI/SD, трей, автозапуск
game-starter/        прототип карткової веб-гри (основа для ігрового агента)
deploy/              install.sh, update.sh, backup.sh, restore.sh
docs/                інструкції українською
```

## Безпека коротко

Ключі API — лише у змінних середовища (`.env` на сервері, не в Git). Hermes недоступний з інтернету. Панель — HTTPS,
пароль + 2FA, захист від підбору, журнал усіх дій. Агенти діють за правилами: гроші, реальні угоди, публікації,
видалення, головна гілка й налаштування сервера — лише з підтвердження власника. Кнопка «Стоп» і команда `stop` у Telegram
миттєво зупиняють усіх агентів.
