# Встановлення Джарвіса на сервер — з iPhone, крок за кроком

Займе 20–30 хвилин. Усі команди можна копіювати й вставляти. Наприкінці ви отримаєте адресу панелі для Safari.

## Що потрібно заздалегідь

1. **VPS від ZAP-Hosting**: Ubuntu 24.04 (або 22.04), Німеччина, 2 ядра, 4–8 ГБ RAM.
   У панелі ZAP запишіть **IP-адресу** сервера і **пароль root**.
2. **Ключ Anthropic API**: console.anthropic.com → Settings → API Keys → Create Key.
   Там же, у Settings → Limits, поставте місячний ліміт витрат (наприклад, $30) — це запобіжник на рівні Anthropic.
3. **Застосунок Termius** з App Store (безкоштовний). Через нього зручно й надійно вставляти команди.
   > Чому не браузерна консоль ZAP: такі консолі іноді підміняють символи `:` `@` `=` під час вставки, і ключі псуються. Якщо все ж користуєтеся нею — набирайте команди уважно.
4. (Необов'язково) **Telegram-бот** — див. [TELEGRAM.md](TELEGRAM.md). Можна додати й пізніше.

## Крок 1. Підключитися до сервера

1. Termius → **Hosts** → **+** → **New Host**.
2. **Address**: IP сервера. **Username**: `root`. **Password**: пароль root з ZAP. Збережіть.
3. Натисніть на хост → **Connect**. Якщо спитає про «fingerprint» — **Continue**.
4. Ви побачите рядок на кшталт `root@server:~#` — можна вводити команди.

## Крок 2. Запустити встановлення

**Варіант А — репозиторій публічний** (у коді немає жодних ключів, тож це безпечно). Вставте одним рядком:

```bash
curl -fsSL https://raw.githubusercontent.com/greenbullhelp/jarvis/main/deploy/install.sh -o install.sh && bash install.sh
```

**Варіант Б — репозиторій приватний.** Спершу створіть на GitHub токен лише на читання:
github.com → Settings → Developer settings → Fine-grained tokens → Generate → Repository access: *Only select* → `jarvis` → Permissions: *Contents: Read-only*. Потім:

```bash
apt-get update && apt-get install -y git && git clone https://github.com/greenbullhelp/jarvis.git /opt/jarvis
```

Git спитає **Username** — введіть `greenbullhelp`, **Password** — вставте токен (символи не видно, так і має бути). Далі:

```bash
bash /opt/jarvis/deploy/install.sh
```

## Крок 3. Відповісти на питання скрипта

Скрипт сам оновить систему, поставить Docker, увімкне файрвол, автооновлення безпеки й захист від підбору паролів. Потім спитає:

| Питання | Що робити |
|---|---|
| Ключ Anthropic API | вставте ключ `sk-ant-...` (символи не показуються) і Enter |
| Домен панелі | просто **Enter** — буде безкоштовна адреса виду `1-2-3-4.sslip.io` з HTTPS. Якщо маєте свій домен — введіть його (спершу направте A-запис на IP сервера) |
| Токен Telegram-бота | Enter, щоб пропустити, або вставте токен |
| Новий пароль (двічі) | придумайте пароль від панелі, **мінімум 10 символів**. Збережіть у «Паролях» iPhone |

Перша збірка триває 5–10 хвилин. Наприкінці буде зелений напис:

```
Готово! Адреса панелі:  https://1-2-3-4.sslip.io
```

## Крок 4. Перший вхід (з 2FA)

1. Відкрийте адресу в **Safari**. (Якщо Safari пише про сертифікат — зачекайте 1–2 хвилини й оновіть: Caddy саме отримує сертифікат.)
2. Введіть пароль, поле коду залиште порожнім → **Увійти**.
3. Панель покаже QR-код і кнопку **«Додати в «Паролі» iPhone»**. Натисніть її → iPhone запропонує зберегти код перевірки → оберіть запис.
   (Або відскануйте QR в Google Authenticator / 1Password на іншому пристрої.)
4. Введіть 6 цифр з «Паролів» → **Підтвердити й увійти**. Готово.
5. Поділитися → **На екран «Додому»** — панель відкриватиметься як застосунок.

Далі при кожному вході: пароль + 6-значний код (iPhone підставляє його сам).

## Крок 5. Перевірити, що все працює

У панелі вгорі: **Hermes** — зелена крапка, **$0.00 / $3** — витрати. Напишіть у чат «Привіт» — за кілька секунд прийде відповідь.

У Termius можна перевірити стан:

```bash
cd /opt/jarvis && docker compose ps
```

Усі три служби (`jarvis-hermes`, `jarvis-panel`, `jarvis-caddy`) мають бути `running` / `healthy`.

## Автозапуск

Нічого робити не треба: Docker і служба `jarvis` стартують самі після перезавантаження сервера. Перевірити:

```bash
reboot
```

Через 2 хвилини панель знову відкриється.

## Захист сервера — що вже зроблено

- **Файрвол (ufw)**: відкрито лише 22 (SSH), 80 і 443 (панель). Hermes і база назовні недоступні.
- **Оновлення безпеки** ставляться автоматично щодня (unattended-upgrades).
- **fail2ban** блокує IP, що підбирають пароль SSH.
- **HTTPS** — сертифікат Let's Encrypt, оновлюється сам (Caddy).
- **Панель**: пароль + 2FA, блокування після 5 невдалих спроб, cookie лише для HTTPS.
- **Ключі** — тільки у файлі `/opt/jarvis/.env` (доступ лише root), не в коді й не в GitHub.

### Рекомендовано: вхід на сервер за ключем замість пароля

1. Termius → **Keychain** → **+** → **Generate Key** (тип ED25519) → збережіть.
2. Відкрийте ключ → **Export to host** → виберіть свій сервер. Перепідключіться — пароль більше не спитає.
3. Лише **після** успішного входу за ключем вимкніть вхід за паролем:

```bash
sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config && systemctl restart ssh
```

Не закривайте поточну сесію, поки не перевірите вхід у новій вкладці. Якщо щось пішло не так — у ZAP завжди є браузерна консоль.

## Оновлення Джарвіса

```bash
bash /opt/jarvis/deploy/update.sh
```

Скрипт зробить резервну копію, завантажить новий код і перезапустить служби.

## Корисні команди

| Що | Команда |
|---|---|
| Стан служб | `cd /opt/jarvis && docker compose ps` |
| Журнал панелі | `docker compose logs -f --tail 50 panel` |
| Журнал Hermes | `docker compose logs -f --tail 50 hermes` |
| Зупинити агентів | `docker compose exec panel python -m app.cli stop` |
| Змінити пароль | `docker compose exec panel python -m app.cli set-password` |
| Скинути 2FA (новий телефон) | `docker compose exec panel python -m app.cli reset-2fa` |
| Змінити ключ API | `nano /opt/jarvis/.env` → змінити рядок → Ctrl+O, Enter, Ctrl+X → `docker compose up -d` |
| Резервна копія | `bash /opt/jarvis/deploy/backup.sh` |

## Якщо щось не працює

- **Панель не відкривається**: `docker compose ps` — чи всі служби `running`? `docker compose logs caddy` — помилки сертифіката? Перевірте, що порти 80/443 відкриті й у панелі ZAP немає власного файрвола, що їх блокує.
- **Hermes червоний**: `docker compose logs hermes --tail 80`. Найчастіше — неправильний ключ Anthropic у `.env`.
- **«Денний ліміт вичерпано»**: Налаштування → Денний ліміт.
- Інструкція з відновлення з нуля — [RECOVERY.md](RECOVERY.md).
