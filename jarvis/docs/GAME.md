# Карткова гра «Властелін» і ігровий агент

## Звідки береться сценарій

Сценарій, концепт і беклог гри зі старого проєкту VLASTELIN AI Office зберігаються в його хмарній базі (Cloudflare D1),
а не в коді. Перенести їх у Джарвіса можна двома способами.

**Спосіб 1 — експорт файлом (комп'ютер з Windows, де вже налаштовано wrangler для VLASTELIN).**
У PowerShell у папці старого проєкту:

```powershell
npx.cmd wrangler d1 execute vlastelin --remote --json --command "SELECT role, title, result, status FROM agent_tasks WHERE status IN ('done','ready')" > game_docs.json
npx.cmd wrangler d1 execute vlastelin --remote --json --command "SELECT k, v FROM state WHERE k='ws'" > game_ws.json
```

Далі в панелі Джарвіса: **Гра та бізнес → Сценарій і документи → Імпорт з VLASTELIN** — по черзі виберіть обидва файли.
Панель сама розбере документи Сценариста, Економіста, Дизайнера, Програміста, а також концепт і беклог гри
(кодування файлу PowerShell — UTF-16 — підтримується).

**Спосіб 2 — вручну з телефона.** На старому сайті відкрийте «Розробка гри», скопіюйте текст концепту чи схваленого документа
→ у Джарвісі «Вставити текст вручну» → назва + текст → Зберегти.

Імпортовані документи стають «біблією гри»: панель додає їх у контекст ігрового агента в кожній його задачі.

## Світ і стартовий набір (поки сценарій не імпортовано)

Оригінальний світ (без чужих персонажів і брендів): королівство на альпійських перевалах, де чотири фракції змагаються за корону Властеліна.

| Фракція | Стиль гри |
|---|---|
| Корона | захисники, споруди, стабільне золото |
| Орден Попелу | заклинання, шкода при смерті бійців |
| Дикі Землі | швидкі атаки, заморожування, велетні |
| Тіньова Гільдія | інформація, контроль бійців суперника |

Кнопка «Додати стартовий набір» у розділі «Гра та бізнес» створює 12 карток цих фракцій.

## Прототип гри

Папка `game-starter/` — робочий прототип веб-гри без збірки (HTML + ES-модулі):
`src/engine.js` — правила (золото до 10, рука 7, стіл 6, «Захисник», «Ривок», ШІ суперника),
`src/main.js` — інтерфейс, `cards.json` — картки, `monetization.json` — посилання на донати,
`engine.test.mjs` — тести (`node engine.test.mjs`).
При встановленні прототип копіюється в робочу папку ігрового агента `data/hermes/workspace/game` (окремий git-репозиторій).

## Як працює ігровий агент

1. Ви пишете Джарвісу (або натискаєте кнопку в «Гра та бізнес»): «Архітектура гри», «Баланс карток», «Наступна фіча», «Монетизація», «Нові картки + графіка».
2. Джарвіс доручає задачу ігровому агенту. Агент працює в `workspace/game`: пише код у гілці `agent/<назва>`, комітить, запускає тести.
   Пуш у `main` заборонено правилами Hermes; злиття в `main` — лише з вашого підтвердження.
3. Нові картки агент додає дією `card`, а описи для малювання — дією `art_request`. Панель додає до опису **єдиний стиль**
   (темне фентезі, темно-синій і чорний, горіх і золото, альпійські мотиви) і ставить задачу ПК-вузлу. Готова картинка з'являється в каталозі.
4. Важливі результати перевіряє Контролер; підсумок приходить у чат.

### Зберігати код гри на GitHub (необов'язково)

1. Створіть на GitHub порожній **приватний** репозиторій для гри (напр. `vlastelin-cards`).
2. Створіть fine-grained токен **лише на цей репозиторій** з правом *Contents: Read and write*.
3. Захистіть гілку `main` у репозиторії гри: Settings → Branches → Add rule → `main` → *Require a pull request before merging*.
4. На сервері: `nano /opt/jarvis/.env` → `AGENT_GH_TOKEN=<токен>`, `GAME_REPO=<ваш-логін>/vlastelin-cards` → `docker compose up -d`.
5. Напишіть Джарвісу: «Підключи репозиторій гри <адреса> як origin і запуш гілки agent/*». Злиття в `main` робите ви на GitHub.

## Монетизація (принципи)

- **Донати** — лише косметика (рамки, сорочки карток, сезонні стилі) і «Підтримай розробника». Жодного продажу сили (no pay-to-win).
- **Банерна реклама** — нижній банер у меню і банер на екрані результатів. **Ніколи** під час бою.
- Посилання для донатів — у панелі («Монетизація») або `monetization.json` гри.
- Публікація гри, підключення рекламної мережі й платіжних сервісів — дії «від вашого імені» й «гроші»: лише з вашого підтвердження.
