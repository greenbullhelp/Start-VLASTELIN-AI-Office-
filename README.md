# VLASTELIN — AI Virtual Office

Персональний командний центр з 3D-сценою (Three.js): панорамний офіс, нічне місто, реалістична планета, голографічне місто і сріблястий AI-асистент.

- `index.html` — розмітка
- `css/style.css` — HUD-стиль панелей
- `js/app.js` — логіка інтерфейсу (налаштування в блоці `CONFIG`)
- `js/office3d.js` — 3D-сцена офісу
- `js/assistant3d.js` — 3D-асистент
- `vendor/three/` — Three.js r160 (MIT, локальна копія — сайт не залежить від CDN)

Кнопка «РЕЖИМ: MAX/ECO» вмикає полегшену графіку для слабких пристроїв.

## AI-агент

Агент працює через сервер-посередник `worker/agent-worker.js` (Cloudflare Worker): ключ Claude API зберігається там у секретах і ніколи не потрапляє на сайт.

1. Зареєструйтеся на dash.cloudflare.com → **Workers & Pages** → **Create** → **Worker**, назвіть `vlastelin-agent`, натисніть **Deploy**.
2. **Edit code** → замініть код вмістом `worker/agent-worker.js` → **Deploy**.
3. **Settings → Variables and Secrets** → додайте:
   - `ANTHROPIC_API_KEY` (тип **Secret**) — ключ з console.anthropic.com;
   - `ACCESS_CODE` (тип **Secret**) — придумайте власний код доступу.
4. Скопіюйте адресу воркера (`https://vlastelin-agent.<нік>.workers.dev`).
5. На сайті: **Налаштування** → вставте адресу і код → **Перевірити зв'язок** → **Зберегти**.

Агент уміє: відповідати й радити, створювати проєкти, змінювати їх прогрес, додавати події в календар. Відповіді можна озвучувати голосом. Аватар збільшується кнопкою ⤢.
