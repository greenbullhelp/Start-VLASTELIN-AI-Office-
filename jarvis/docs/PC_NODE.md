# Вузол Джарвіса на домашньому ПК (Windows)

ПК виконує важку роботу: **графіку** (ComfyUI або Stable Diffusion, оптимізовано під 8 ГБ відеопам'яті) і **відео**
(FFmpeg — нарізка, склейка, формати YouTube і Shorts; Whisper — субтитри). Сервер може попросити ПК лише про дії з білого списку,
а ПК додатково виконує тільки ті дії, які ви залишили в його `config.toml`.

Якщо ПК вимкнений — задачі чекають у черзі. Термінову задачу графіки можна виконати через платний API (Stability AI) —
лише після вашого «Дозволити» в панелі чи Telegram.

## 1. Tailscale (захищений тунель між ПК і сервером)

1. Зареєструйтеся на tailscale.com (безкоштовно).
2. **На сервері** (Termius):
   ```bash
   curl -fsSL https://tailscale.com/install.sh | sh && tailscale up
   ```
   Відкрийте посилання, яке покаже команда, і підтвердіть вхід. Потім дізнайтеся адресу сервера в Tailscale:
   ```bash
   tailscale ip -4
   ```
   Вийде щось на кшталт `100.101.102.103`.
3. Дозвольте панелі слухати цю адресу для ПК-вузла:
   ```bash
   cd /opt/jarvis && sed -i "s/^TAILSCALE_IP=.*/TAILSCALE_IP=$(tailscale ip -4)/" .env && ufw allow in on tailscale0 to any port 8100 && docker compose up -d
   ```
4. Токен вузла (знадобиться на ПК):
   ```bash
   grep NODE_TOKEN /opt/jarvis/.env
   ```
5. **На ПК**: встановіть Tailscale для Windows з tailscale.com/download і увійдіть тим самим акаунтом.

## 2. Програми на ПК

- **Python 3.12** з python.org (під час встановлення — галочка *Add python.exe to PATH*).
- **FFmpeg**: `winget install Gyan.FFmpeg` у PowerShell (або архів з gyan.dev, папку `bin` додати в PATH).
- **Графіка** — одне з двох:
  - **ComfyUI** (рекомендовано): портативна версія з github.com/comfyanonymous/ComfyUI → `run_nvidia_gpu.bat`.
    Модель (checkpoint) покладіть у `ComfyUI/models/checkpoints`. Для 8 ГБ: **SDXL base 1.0** (`max_side = 1216`) або **SD 1.5** (`max_side = 768`).
    ComfyUI сам вмикає економію пам'яті на 8 ГБ.
  - **Stable Diffusion WebUI Forge/AUTOMATIC1111**: запуск з `--api` (для 8 ГБ ще `--medvram-sdxl`), у `config.toml` — `image_backend = "sd"`.
- **Whisper** (субтитри) ставиться автоматично разом із вузлом (`faster-whisper`). Для відеокарти NVIDIA потрібні CUDA 12 і cuDNN 9;
  без них вузол сам перейде на процесор (повільніше).

## 3. Встановлення вузла

1. Скопіюйте папку `node` з репозиторію Джарвіса на ПК, напр. у `C:\JarvisNode` (GitHub → Code → Download ZIP).
2. Двічі клацніть **`install_windows.bat`**. Він:
   - створить окреме середовище Python і поставить пакети;
   - відкриє Блокнот з `config.toml` — вставте `server = "http://100.x.y.z:8100"` (адреса сервера з кроку 1) і `token = "..."`, збережіть, закрийте;
   - перевірить зв'язок (`Сервер: OK, вузол онлайн`), інструменти (ffmpeg, whisper, ComfyUI) і відеокарту;
   - зареєструє **автозапуск разом із Windows** (Планувальник завдань → `JarvisNode`) і запустить вузол.
3. Біля годинника з'явиться значок: **зелений** — онлайн, **жовтий** — виконує задачу, **червоний** — немає зв'язку.
   У панелі (розділ «Агенти») ПК-вузол теж показується онлайн/офлайн.

Перевірити вручну: `C:\JarvisNode\.venv\Scripts\python jarvis_node.py --check`. Журнал — `jarvis_node.log`.
Вимкнути автозапуск — `uninstall_windows.bat`.

## Білий список дій

| Дія | Що робить |
|---|---|
| `ping` | перевірка зв'язку |
| `comfy_generate`, `sd_generate` | картинка за описом (картки, фони, іконки) в єдиному стилі гри |
| `ffmpeg_cut` | вирізати фрагмент відео |
| `ffmpeg_concat` | склеїти кілька відео |
| `ffmpeg_transcode` | формат: `youtube_1080p`, `shorts_vertical` (1080×1920), `preview_480p`, `audio_mp3` |
| `whisper_subtitles` | субтитри `.srt` (українська за замовчуванням) |
| `burn_subtitles` | «вшити» субтитри у відео |
| `transcribe` | розпізнати голосове (якщо на сервері `STT_PROVIDER=node`) |

Сервер перевіряє параметри (лише числа в межах, файли тільки всередині робочої папки) і ніколи не надсилає команд оболонки.
Щоб заборонити дію — видаліть її з `allowed_actions` у `config.toml` і перезапустіть вузол (значок → Вийти, потім запустіть знову).

## Як передати відео на обробку

Покладіть файли в робочу папку сервера `data/hermes/workspace/video/` (або попросіть відео-агента завантажити їх),
напишіть Джарвісу, напр.: «Зроби з video/raw.mp4 вертикальний ролик 30 секунд з 1:10 і субтитрами».
Результати з'являються там само на сервері; ПК зберігає копії в `C:/JarvisNode/work`.
