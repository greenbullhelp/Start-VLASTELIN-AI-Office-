# Telegram — додатковий канал зв'язку з Джарвісом

У Telegram можна писати й надсилати голосові, отримувати відповіді, щоденний звіт, запити на підтвердження,
і миттєво зупинити всіх агентів словом `stop`. Бот відповідає **лише вам** — повідомлення від інших ігноруються й пишуться в журнал.

## Підключення (5 хвилин, з iPhone)

1. У Telegram знайдіть **@BotFather** → `/newbot` → придумайте назву (напр. «Мій Джарвіс») і ім'я, що закінчується на `bot`.
   BotFather надішле **токен** вигляду `1234567890:AA...` — скопіюйте.
2. Знайдіть **@userinfobot** → `/start` → він покаже ваш **Id** (лише цифри) — скопіюйте.
3. Відкрийте свого нового бота й натисніть **Start** (інакше бот не зможе написати першим).
4. На сервері (Termius):
   ```bash
   cd /opt/jarvis && nano .env
   ```
   Заповніть два рядки: `TELEGRAM_BOT_TOKEN=...` і `TELEGRAM_OWNER_ID=...`. Збережіть: **Ctrl+O**, Enter, **Ctrl+X**. Далі:
   ```bash
   docker compose up -d
   ```
5. Напишіть боту «Привіт». У панелі → Налаштування → «Telegram: підключено».

## Команди

| Команда | Дія |
|---|---|
| будь-який текст / голосове | задача Джарвісу (відповідь прийде сюди ж) |
| `stop` або `/stop` | **миттєво зупинити всіх агентів** (і демо-торгівлю) |
| `/resume` | продовжити роботу |
| `/status` | що зараз виконується і скільки витрачено |
| `/report` | звіт зараз |
| `/approve 12` | дозволити запит №12 |
| `/reject 12 причина` | відхилити запит №12 |

Голосові з Telegram розпізнає сервер (Whisper) або ПК-вузол — залежно від `STT_PROVIDER` у `.env`.
