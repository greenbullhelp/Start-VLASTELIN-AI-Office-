## Запуск і перевірка локально
- Сервер: `python -m http.server 8765`, далі відкрити http://localhost:8765. Через `file://` модулі не завантажаться.
- Тести воркера: `node tests/worker.test.mjs` (мають бути всі PASS).

## Ключові технічні рішення
### Інтерфейс (`js/app.js`)
- Усі налаштування користувача — в об'єкті `CONFIG` на початку файлу: ім'я, роль, місто й координати, репозиторій, `agentUrl`, стартові проєкти й події.
- Дані зберігаються в `localStorage`: `vl_projects` (`{name, progress, icon}`), `vl_events` (`{t, title}`), `vl_agent` (`{url, code, voice}`), `vl_history`. Завжди обгортай доступ у try/catch (див. `store`).
- Погода — Open-Meteo (без ключа). Статуси перевіряються по-справжньому: інтернет, GitHub API, `/health` агента. **Не показуй фальшивих «онлайн»**: власник цінує чесні статуси.
- Голос: Web Speech API (`uk-UA`) на вхід, `speechSynthesis` на вихід (вмикається в налаштуваннях).
  - Вхід: одне натискання 🎤 → слухає (`continuous` + `interimResults`), пауза 1.5 с = «договорив» → надсилає сам; повторне натискання — надіслати одразу; тиша 8 с — зупинка з чесною підказкою. «Режим розмови» (`vl_talk`) — після озвучення відповіді слухає знову.
  - Вихід: `pickVoice()` шукає чоловічий uk-голос за назвою (Microsoft Ostap в Edge); на iPhone є лише жіночий (Lesya) — так погоджено з власником. Вибір голосу й «Прослухати» — у Налаштуваннях (`agent.voiceName`). Хмарний TTS (Azure Ostap Neural) — можливе покращення пізніше.
- Режим **MAX/ECO**: `officeApi.setEco` / `bustApi.setEco` вимикають bloom, знижують pixelRatio і сповільнюють анімації.
- Без WebGL на `body` ставиться клас `no-webgl` (замість андроїда показується емблема). Лоадер має запобіжник 7 с.

### 3D-офіс (`js/office3d.js`)
- Камера центрується на вільній частині зони `#stage` через `camera.setViewOffset` з урахуванням панелі асистента (функція `resize`).
- Що вже налаштовано, щоб не було пересвіту: bloom `(.62, .5, .82)`, exposure `.92`, місто `emissiveIntensity .75`. Підвищувати обережно.
- Місто: `InstancedMesh` + текстури вікон; UV масштабуються під розмір інстанса в `onBeforeCompile`. Будинки стоять нижче рівня офісу (`CITY_Y = -34`), щоб створювати відчуття висоти.
- Планета: процедурні текстури 1024×512 (суходіл, бамп, вогні міст), хмари, атмосфера, сітка паралелей/меридіанів. Вогні міст видно лише на нічному боці (`onBeforeCompile`, `uSunDir`).
- Новий об'єкт додавай у потрібну групу (`city`, `office`, `holo`, `globe`) й анімуй у `frame()`.

### Асистент «Професор» (`js/assistant3d.js`)
- Мальований стиль: `MeshToonMaterial` з 4-ступеневою `toonRamp()` + контур `outlineMaterial` (зворотні грані, зсув по нормалі в просторі камери; `ink(mesh)`). Волосся — шумні «хмари» `puffGeometry` + звужені пасма `hairStrands` (злиті в одну геометрію `merge`). Светр — шейдер з V-вирізом сорочки. Стан показує ореол за головою (блакитний/золотий/фіолетовий), очі стежать за курсором, кліпають повіки, рот рухається при мовленні. API той самий.
### (архів) Андроїд — старий варіант
- Голова — сфера 256×200, деформована функцією `sculpt()`: гаусові «горби» й «гряди» (`g2`, `segG`). Торс — `LatheGeometry` з анатомічними зміщеннями в `bodyGeometry()`. Шов lathe розвернуто назад (`phiStart = π`).
- Хром: `MeshPhysicalMaterial` (metalness 1, roughness ~.06) + PMREM з власного оточення `chromeEnvironment()` (небо з хмарами, сонце, сині й золоті панелі).
- API: `speak(sec)`, `listen(bool)`, `think(bool)`, `setBig(bool)`, `setEco(bool)`. Колір очей: блакитний — звичайний стан, золотий — слухає, фіолетовий — думає.

### AI-агент (`worker/agent-worker.js`)
- Ключ Claude API **ніколи не кладемо на сайт**: сайт статичний, і ключ побачили б усі. Він живе лише в секретах воркера.
- Захист: CORS + перевірка `Origin` (`ALLOWED_ORIGINS`, за замовчуванням `https://greenbullhelp.github.io`), заголовок `X-Access-Code` = секрет `ACCESS_CODE`.
- `GET /health` → `{ok, model, protected, configured}`; `POST /chat` `{messages, context}` → `{reply, actions}`.
- Модель: `MODEL` або `claude-sonnet-5-5`. Інструменти: `create_project`, `update_project_progress`, `add_event`. Їх виконує **браузер** (`runAction` в `app.js`), воркер лише повертає їх.
- Історія розмови: лише текст (до 20 повідомлень), воркер нормалізує її (починається з user, ролі чергуються).
- Щоб додати інструмент: опиши його в `TOOLS` у воркері, обробку додай у `runAction` в `app.js`, а в тестах — перевірку.

Ключі: projects, events, ws, history. На сайті `store.set` ставить у чергу лише справжні зміни (не перший запис значень за замовчуванням і не дані з сервера); `sync.run(true)` — при завантаженні, кожні 60 с, при поверненні на вкладку, після збереження налаштувань. Перед першим прийомом даних локальна копія → `vl_backup_<key>`. Статус «Хмара» — у списках статусів розділів.
Реалізація кроку 0 у воркері: `pickTier()` (SMART_RE / довжина > 800 / `mode: "deep"` з галочки «Глибокий аналіз») → `TIERS` fast=Haiku effort low, smart=Sonnet effort medium; `costUsd()` за `PRICES`; денний бюджет у KV `BUDGET` (ключ `spend:YYYY-MM-DD`, ліміт `DAILY_BUDGET_USD` у `wrangler.toml`, 429 до виклику API). Відповідь `/chat`: `{reply, actions, model, tier, cost, budget}`.
Чат: поле команди / бульбашка відкривають вікно `#chatwin` (з 18.11.2026 — панель, що виїжджає знизу екрана: на ПК по центру до 860px, на телефоні на всю ширину, 78% висоти) (історія, фото до 4 шт., стиснення до 1280px JPEG у браузері; у `vl_history` фото не зберігаються, лише кількість `photos`). Фото йдуть полем `images` лише з останнім повідомленням.
**Крок 0 «Економія»** — розподіл задач за витратою токенів:
- Прості задачі (розмова, створити проєкт/подію) → `claude-haiku-5-5` ($0.10/$0.50 за 1M), низький effort.
- Аналіз і складні задачі → `claude-sonnet-5-5` ($2/$10 за 1M), effort за потребою.
- Зараз воркер не задає effort → Sonnet 5.5 думає на default `high`: для чату поставити `low` (перевірити на живому запиті з власником перед деплоєм).
- Кешування стабільного префікса (правила, пам'ять); денний бюджет у воркері (рахувати `usage`, зупинятися з чесним повідомленням).
- Агенти GitHub (крок 5) — перевірити запуск через підписку власника замість балансу API.

## Можливі наступні кроки (якщо власник не дав іншого)
1. Допомогти розгорнути воркер (можна через `npx wrangler deploy` з `wrangler.toml`, якщо на комп'ютері є Node).
2. Наповнити розділи меню (зараз клік показує лише заглушку в бульбашці асистента).
3. Реальні фінанси (таблиця/банк) замість демо.
4. Інструменти агента для GitHub: створення issue/коміту через воркер з окремим токеном.
5. Постійне сховище замість `localStorage` (наприклад, Cloudflare KV / D1), щоб дані були спільними між пристроями.
