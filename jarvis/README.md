# Джарвіс — персональний AI-асистент

Джарвіс працює цілодобово на сервері, приймає задачі з телефона текстом і голосом, роздає роботу команді агентів
і звітує. Мозок — [Hermes Agent](https://github.com/NousResearch/hermes-agent) від Nous Research на моделях Claude;
керування — приватна веб-панель «Командний центр» (лише для власника, пароль + 2FA).

Напрями: ігри (карткова гра з донатами й банерною рекламою), монтаж відео, аналітика й торгівля золотом (поки лише демо), дослідження.

## Статус проєкту

| Етап | Що входить | Стан |
|---|---|---|
| 1. База | Docker Compose (Hermes + панель + HTTPS), вхід з 2FA, чат текстом і голосом (хвиля), середня модель, правила, журнал, «Стоп» | ✅ готово, протестовано |
| 2. Команда | Контролер, 4 виконавці, блокування файлів, автоперемикання моделей, вартість задач, денний ліміт | ✅ готово, протестовано |
| 3. Огляд | Щоденний звіт, розділи Ринок / Гра та бізнес / Звіти, жива схема агентів, Telegram | ⏳ в роботі |
| 4. Вузол на ПК | Клієнт Windows + Tailscale: графіка (ComfyUI/SD), потім відео (FFmpeg + Whisper) | ⏳ далі |
| 5. Ігровий агент | Архітектура, механіки, баланс, код карткової гри, монетизація | ⏳ далі |
| 6. Трейдинговий агент | Аналітика золота, сигнали, журнал, демо-рахунок, ліміти ризику | ⏳ далі |

Останнє оновлення: 19.11.2026. Тести: `cd panel && python -m pytest -q` — усі проходять.
Перевірено з реальним Hermes Agent 0.23.2 у Docker (запуск, статус, «Стоп», обробка помилок).

**Що потрібно від власника, щоб запустити**: VPS, ключ Anthropic API, виконати [інструкцію встановлення](docs/SERVER_SETUP.md).

## Структура

```
docker-compose.yml   три служби: hermes, panel, caddy
Caddyfile            HTTPS для панелі
.env.example         шаблон налаштувань (справжні ключі — лише в .env на сервері)
hermes/              конфігурація й характер Hermes (config.yaml, SOUL.md)
panel/               веб-панель: FastAPI (app/) + інтерфейс без збірки (static/) + тести (tests/)
deploy/              install.sh, update.sh, backup.sh, restore.sh
docs/                інструкції українською
```

## Безпека коротко

Ключі API — лише у змінних середовища (`.env` на сервері, не в Git). Hermes недоступний з інтернету. Панель — HTTPS,
пароль + 2FA, захист від підбору, журнал усіх дій. Агенти діють за правилами: гроші, реальні угоди, публікації,
видалення, головна гілка й налаштування сервера — лише з підтвердження власника. Кнопка «Стоп» і команда `stop` у Telegram
миттєво зупиняють усіх агентів.
