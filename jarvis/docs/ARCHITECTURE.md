# Як влаштований Джарвіс

```
iPhone / комп'ютер ──HTTPS──► Caddy (443) ──► Панель (FastAPI, :8000) ──HTTP, мережа Docker──► Hermes Agent (:8642)
       Telegram ◄──────────────── панель (бот, довге опитування)                                     │
ПК-вузол (Windows) ──Tailscale──► панель :8100 (/node/*)                                     Claude API (Anthropic)
```

Три контейнери Docker Compose:

| Служба | Що робить | Доступ ззовні |
|---|---|---|
| `caddy` | HTTPS-сертифікат, проксі до панелі | 80, 443 |
| `panel` | вхід (пароль+2FA), чат, черга задач, команда агентів, правила, журнал, бюджет, звіти, Telegram, ринок, гра, ПК-вузол | лише через Caddy; порт 8100 — лише на адресі Tailscale для ПК-вузла |
| `hermes` | Hermes Agent від Nous Research: модель + інструменти (термінал, файли, веб-пошук, пам'ять) у робочій папці | **немає** (лише мережа Docker) |

## Як панель обмінюється даними з Hermes

Hermes запущено з увімкненим **API-сервером** (`API_SERVER_ENABLED=true`). Він слухає лише мережу Docker і вимагає
секрет `API_SERVER_KEY` (генерується при встановленні, лежить у `.env`).

**Панель → Hermes** (`panel/app/brain.py`, клас `HermesBrain`):

1. `POST /v1/runs` з тілом
   `{"input": "<задача>", "instructions": "<роль агента + правила + контекст>", "session_id": "jarvis-<агент>-g<покоління>", "model": "claude-sonnet-5-5", "provider": "anthropic", "model_options": {"reasoning_effort": "medium"}}`
   → `{"run_id": "run_…"}`. Модель вибирає панель для кожної задачі (дешева / середня / сильна).
2. `GET /v1/runs/{run_id}` кожні 1–4 с → `status` (`completed` / `failed` / `cancelled`), `output` (текст відповіді),
   `usage` (токени, включно з кешем) і `runtime.model` (яка модель реально відповіла). З `usage` панель рахує вартість.
3. Кнопка **«Стоп»** → `POST /v1/runs/{run_id}/stop` для кожного активного запуску (Hermes зупиняє агента на найближчому безпечному кроці).

Кожен агент — окрема **сесія Hermes** (`session_id`), тож у нього своя пам'ять розмови. «Перезапуск агента» = нове покоління сесії.

**Hermes → панель**: агент дописує в кінець відповіді блок

````
```actions
[{"type": "delegate", "agent": "game", "title": "…", "brief": "…", "important": true, "paths": ["game/src"]}]
```
````

Панель вирізає цей блок із тексту і пропускає **кожну** дію через правила (`panel/app/rules.py`):
дозволені виконуються одразу, «з підтвердженням» стають запитом у панелі й Telegram, заборонені відхиляються з записом у журнал.
Повний перелік дій — у `panel/app/agents.py` (`ACTION_DOC`).

Спільна **робоча папка**: `data/hermes/workspace` = `/opt/data/workspace` у Hermes = `/data/workspace` у панелі.
Там код гри, відео, результати ПК-вузла.

Перевірено на Hermes Agent 0.23.2 (образ `nousresearch/hermes-agent:stable`): створення запуску, опитування статусу,
зупинка (`cancelled`), помилка ключа (`failed` з поясненням, яке панель показує в чаті).

## Команда агентів

```
Власник ─► Джарвіс ─► (delegate) ─► Ігровий · Відео · Трейдинговий · Дослідник
                                         │  важливі результати
                                         ▼
                                     Контролер ─► OK / доопрацювання (до 2 разів) / «потрібне ваше рішення»
                                         │
                       Джарвіс збирає звіт по задачі ◄─┘
```

- **Черга й паралельність**: одночасно працює до `MAX_PARALLEL_AGENTS` задач (2 для 2-ядерного сервера).
- **Блокування файлів** (частина Контролера): кожен виконавець має свою область (`game/`, `video/`, `trading/`) і папки з `paths`.
  Якщо дві задачі змінюють перетинні папки, друга чекає (статус «чекає», запис у журналі `lock_wait`).
- **Контролер** перевіряє задачі з `important: true` і повертає JSON-вердикт. Невдалі — на доопрацювання, після двох — рішення за вами.

## Моделі й гроші

- Рівні: дешева `claude-haiku-5-5`, **середня `claude-sonnet-5-5` (за замовчуванням)**, сильна `claude-opus-5-5` (змінюються в `.env`).
- Автовибір (`panel/app/models.py`): короткі прості повідомлення й перевірки Контролера → дешева; архітектура, стратегія,
  глибокий аналіз, дуже довгі задачі → сильна; решта → середня. Ручний вибір — у Налаштуваннях або в чаті для одного повідомлення.
- **Денний ліміт**: перед кожним запуском панель перевіряє залишок. Якщо грошей мало — знижує модель, якщо зовсім немає — не запускає.
- Вартість кожного запуску пишеться в таблицю `costs` і показується в чаті, задачах, звітах.
- Допоміжні виклики Hermes (назви сесій, стиснення контексту) йдуть на дешевій моделі й не потрапляють у `usage` запуску —
  тому ставте ще й місячний ліміт на console.anthropic.com як другий запобіжник.

## Безпека

- Вхід: пароль (scrypt) + TOTP 2FA; 5 невдалих спроб за 15 хв — блокування IP; cookie `HttpOnly; Secure; SameSite=Strict`.
- Усі зміни через API — лише із заголовком `X-Jarvis: 1` (захист від CSRF), суворий CSP.
- Секрети — тільки в `.env`. Панель вирізає ключі з будь-якого тексту (`core.redact`), Hermes має `redact_secrets` і заборони
  на `printenv`, читання `.env`, `git push` у `main`, зміну файрвола тощо (`hermes/config.yaml`).
- Журнал `audit` фіксує вхід, кожну дію агентів, вибір моделі, підтвердження, «Стоп», помилки.
- «Стоп» (кнопка, `stop` у Telegram, `python -m app.cli stop`) миттєво: зупиняє запуски Hermes, скасовує задачі, черги ПК, демо-торгівлю.

## Дані

`data/panel/jarvis.db` — SQLite: власник, сесії, повідомлення, задачі, витрати, підтвердження, журнал, проєкти, ідеї, звіти,
ПК-вузол, ринок, гра. `data/hermes/` — пам'ять, навички й сесії Hermes. Резервні копії — `deploy/backup.sh`.
