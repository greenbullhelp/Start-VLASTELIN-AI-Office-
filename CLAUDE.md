## Що це за проєкт
Персональний **AI-офіс-дашборд** з 3D-сценою. Надалі це робочий простір для AI-агента.
- Репозиторій: `greenbullhelp/Start-VLASTELIN-AI-Office-`
- Сайт (GitHub Pages з `main`, корінь): https://greenbullhelp.github.io/Start-VLASTELIN-AI-Office-/

## ⚠️ Обмеження інтелектуальної власності (важливо)
Власник надсилав референси з персонажами Marvel: Iron Man/JARVIS, Silver Surfer. **Не відтворюй цих персонажів, їхніх назв і логотипів** і не завантажуй їхніх 3D-моделей. Ця межа вже погоджена:
- бренд — **VLASTELIN** (з назви репозиторію), а не JARVIS/STARK;
- асистент — **оригінальний хромовий андроїд** зі своїми рисами: сяючі лінії на скронях, «аудіо-вузли» замість вух, шийні сегменти, шестикутне ядро на грудях. Без дошки для серфінгу й без копіювання конкретного персонажа;
- емблема — власний шестикутник з ядром (SVG-символ `#emblem` в `index.html`).

## Структура
```
index.html            розмітка; importmap для three
css/style.css         HUD-стиль (зрізані кути через clip-path, градієнтні рамки, адаптив ≤1300/≤900px)
js/app.js             логіка UI: CONFIG, годинник, погода, проєкти, календар, голос, агент, налаштування, статуси
js/office3d.js        3D-офіс: небо, місто, вікна, платформа, голо-місто, планета, bloom
js/assistant3d.js     3D-андроїд: скульптура голови/торса, хромове оточення, анімації
js/noise.js           Perlin 3D + fbm для процедурних текстур
worker/agent-worker.js  Cloudflare Worker — посередник до Claude API
tests/worker.test.mjs   тести воркера (node, з імітацією API)
vendor/three/         Three.js r160 (локальна копія, без CDN)
```
**Збірки немає**: звичайні ES-модулі. `three` і `three/addons/` підключені через importmap на `vendor/three/`. CDN свідомо не використовуємо.

## Кеш браузера (важливо при кожному оновленні сайту)
GitHub Pages віддає файли з `max-age=600`, і власник бачив стару версію після публікації. Тому в `index.html` у `css/style.css?v=…` і `js/app.js?v=…` стоїть версія, а `app.js` передає її 3D-модулям (`VER` з `import.meta.url`). **Після кожної зміни CSS/JS піднімай `?v=` в `index.html`.** Сама `index.html` може кешуватися до 10 хв: якщо власник не бачить змін, попроси оновити сторінку через кілька хвилин.

## Розділи навігації
Пункт меню відкриває HUD-панель `#spanel` (`VIEWS` в `app.js`, hash-маршрути `#projects` тощо). У кожному розділі є вкладки «Огляд / Технічні завдання / Вікна»; ТЗ і вікна зберігаються в `localStorage` `vl_ws` = `{[section]: {tasks:[{title,desc,status,at}], wins:[{title,text,at}]}}`. Статуси ТЗ: new → work → done. На слабких пристроях вмикається клас `lite` (`detectLite()` в `office3d.js`, примусово `?q=lite|max`).

## Запуск і перевірка локально
- Сервер: `python -m http.server 8765`, далі відкрити http://localhost:8765. Через `file://` модулі не завантажаться.
- Тести воркера: `node tests/worker.test.mjs` (мають бути всі PASS).
- Візуальна перевірка робилася скриншотами через Playwright + Chrome з `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`. Програмний WebGL повільний, тому чекай 15 с і ставлять великий timeout на скриншот. Перевіряй два розміри: 1440×900 і 400×860.
- Під час перевірки консоль браузера має бути без помилок.

## Ключові технічні рішення
### Інтерфейс (`js/app.js`)
- Усі налаштування користувача — в об'єкті `CONFIG` на початку файлу: ім'я, роль, місто й координати, репозиторій, `agentUrl`, стартові проєкти й події.
- Дані зберігаються в `localStorage`: `vl_projects` (`{name, progress, icon}`), `vl_events` (`{t, title}`), `vl_agent` (`{url, code, voice}`), `vl_history`. Завжди обгортай доступ у try/catch (див. `store`).
- Погода — Open-Meteo (без ключа). Статуси перевіряються по-справжньому: інтернет, GitHub API, `/health` агента. **Не показуй фальшивих «онлайн»**: власник цінує чесні статуси.
- Голос: Web Speech API (`uk-UA`) на вхід, `speechSynthesis` на вихід (вмикається в налаштуваннях).
- Режим **MAX/ECO**: `officeApi.setEco` / `bustApi.setEco` вимикають bloom, знижують pixelRatio і сповільнюють анімації.
- Без WebGL на `body` ставиться клас `no-webgl` (замість андроїда показується емблема). Лоадер має запобіжник 7 с.

### 3D-офіс (`js/office3d.js`)
- Камера центрується на вільній частині зони `#stage` через `camera.setViewOffset` з урахуванням панелі асистента (функція `resize`).
- Що вже налаштовано, щоб не було пересвіту: bloom `(.62, .5, .82)`, exposure `.92`, місто `emissiveIntensity .75`. Підвищувати обережно.
- Місто: `InstancedMesh` + текстури вікон; UV масштабуються під розмір інстанса в `onBeforeCompile`. Будинки стоять нижче рівня офісу (`CITY_Y = -34`), щоб створювати відчуття висоти.
- Планета: процедурні текстури 1024×512 (суходіл, бамп, вогні міст), хмари, атмосфера, сітка паралелей/меридіанів. Вогні міст видно лише на нічному боці (`onBeforeCompile`, `uSunDir`).
- Новий об'єкт додавай у потрібну групу (`city`, `office`, `holo`, `globe`) й анімуй у `frame()`.

### Андроїд (`js/assistant3d.js`)
- Голова — сфера 256×200, деформована функцією `sculpt()`: гаусові «горби» й «гряди» (`g2`, `segG`). Торс — `LatheGeometry` з анатомічними зміщеннями в `bodyGeometry()`. Шов lathe розвернуто назад (`phiStart = π`).
- Хром: `MeshPhysicalMaterial` (metalness 1, roughness ~.06) + PMREM з власного оточення `chromeEnvironment()` (небо з хмарами, сонце, сині й золоті панелі).
- API: `speak(sec)`, `listen(bool)`, `think(bool)`, `setBig(bool)`, `setEco(bool)`. Колір очей: блакитний — звичайний стан, золотий — слухає, фіолетовий — думає.

### AI-агент (`worker/agent-worker.js`)
- Ключ Claude API **ніколи не кладемо на сайт**: сайт статичний, і ключ побачили б усі. Він живе лише в секретах воркера.
- Захист: CORS + перевірка `Origin` (`ALLOWED_ORIGINS`, за замовчуванням `https://greenbullhelp.github.io`), заголовок `X-Access-Code` = секрет `ACCESS_CODE`.
- `GET /health` → `{ok, model, protected, configured}`; `POST /chat` `{messages, context}` → `{reply, actions}`.
- Модель: `MODEL` або `claude-sonnet-5-5`. Інструменти: `create_project`, `update_project_progress`, `add_event`. Їх виконує **браузер** (`runAction` в `app.js`), воркер лише повертає їх.
- Історія розмови: лише текст (до 20 повідомлень), воркер нормалізує її (починається з user, ролі чергуються).
- Щоб додати інструмент: опиши його в `TOOLS` у воркері, обробку додай у `runAction` в `app.js`, а в тестах — перевірку.

## Правила для агентів (погоджено власником 17.11.2026)
Записані в `RULES` у `worker/agent-worker.js` і обов'язкові для будь-якого розвитку агентів:
- Мінімальні доступи: GitHub-токен для асистента лише на цей репозиторій і лише на потрібні дії; зберігати тільки в секретах воркера.
- Пряма зміна `main` агентами заборонена: лише issue/PR, які власник схвалює сам. (Це стосується агентів сайту; коміти Claude Code за прямим дорученням власника — як і раніше.)
- Ліміт витрат на console.anthropic.com; про дорогі задачі попереджати заздалегідь.
- Видалення, платежі, доступи й усе незворотне — лише з явного дозволу власника.
- Економія токенів: історія 10 повідомлень, до 2000 символів на повідомлення, `max_tokens` 600, короткі відповіді.
- Правила в промпті — лише орієнтир для моделі; ті самі обмеження треба забезпечувати технічно (які інструменти є, які права в токена).
